# skkuding-study

스터디용 프로젝트입니다. 각 스터디는 별도의 브랜치에서 진행됩니다.

> 이 `stable` 브랜치에는 스터디 코드가 없습니다. 아래 브랜치로 이동해주세요.

## 스터디 브랜치

- 브랜치 이름 규칙: `day-n-스터디이름` (필요시 `-v2`, `-backend` 처럼 세부 주제 추가)
